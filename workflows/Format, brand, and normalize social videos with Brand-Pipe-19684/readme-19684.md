# Format, brand, and normalize social videos with Brand-Pipe

### 1. Workflow Overview

This workflow automates the formatting, branding, and audio normalization of raw video clips (generated by AI or sourced from stock platforms) to meet the requirements of platforms like YouTube Shorts, TikTok, and Instagram Reels, without requiring local FFmpeg installations. 

The logic is grouped into three functional blocks:
- **1.1 Input Reception & Initialization:** Triggers the execution manually and sets up the required video configuration parameters (source URL, logo URL, target format, and audio normalization flag).
- **1.2 Video Processing & Validation:** Sends the parameters securely to the Brand-Pipe API using an idempotency key and a Header Auth credential, then checks if the API execution was successful.
- **1.3 Output & Error Handling:** Branching logic that either downloads the finalized MP4 file into a binary property for downstream publishing platforms (success path) or terminates execution and surfaces the error message (failure path).

### 2. Block-by-Block Analysis

#### Block 1.1: Input Reception & Initialization
- **Overview:** Starts the manual process and defines the source video attributes, target formatting, and branding elements needed for the transformation.
- **Nodes Involved:** 
  - `Run`
  - `Set video`

##### Node Details: `Run`
- **Type and Technical Role:** `n8n-nodes-base.manualTrigger` (Trigger Node)
- **Configuration Choices:** Default manual execution trigger.
- **Key Expressions or Variables:** None.
- **Input / Output Connections:** Input: None (Entry point) | Output: `Set video`
- **Version-Specific Requirements:** Type version 1.
- **Edge Cases or Potential Failure Types:** None (manual execution only).

##### Node Details: `Set video`
- **Type and Technical Role:** `n8n-nodes-base.set` (Data Transformation / Assignment Node)
- **Configuration Choices:** Assigns hardcoded sample values to string and boolean parameters (`video_url`, `logo_url`, `format`, `audio_normalize`).
- **Key Expressions or Variables:** Assigns values:
  - `video_url`: `https://test-videos.co.uk/vids/bigbuckbunny/mp4/h264/360/Big_Buck_Bunny_360_10s_1MB.mp4`
  - `logo_url`: `https://www.brand-pipe.com/logo.png`
  - `format`: `vertical`
  - `audio_normalize`: `true`
- **Input / Output Connections:** Input: `Run` | Output: `Brand-Pipe process`
- **Version-Specific Requirements:** Type version 3.4.
- **Edge Cases or Potential Failure Types:** Invalid or inaccessible URLs will cause downstream processing failures in the API.

---

#### Block 1.2: Video Processing & Validation
- **Overview:** Submits the video processing payload to the external Brand-Pipe API with an idempotency key, handles authentication, and evaluates the success status of the response.
- **Nodes Involved:** 
  - `Brand-Pipe process`
  - `Success?`

##### Node Details: `Brand-Pipe process`
- **Type and Technical Role:** `n8n-nodes-base.httpRequest` (API Integration Node)
- **Configuration Choices:** Sends a `POST` request to `https://api.brand-pipe.com/v1/process` with a 5-minute timeout (`300000ms`) and prevents node failure on HTTP errors (`neverError: true`). Uses Generic Header Authentication.
- **Key Expressions or Variables:** 
  - JSON Body: `={{ JSON.stringify({ video_url: $json.video_url, logo_url: $json.logo_url, format: $json.format, audio_normalize: $json.audio_normalize }) }}`
  - Idempotency-Key Header: `={{ JSON.stringify({ video_url: $json.video_url, logo_url: $json.logo_url, format: $json.format, audio_normalize: $json.audio_normalize }).hash('sha256') }}`
- **Input / Output Connections:** Input: `Set video` | Output: `Success?`
- **Version-Specific Requirements:** Type version 4.2.
- **Credentials Required:** `Brand-Pipe API Key` (Header Auth type, header name `X-API-Key`).
- **Edge Cases or Potential Failure Types:** API timeouts on long clips, invalid API keys resulting in 401/403 errors, or invalid asset URLs.

##### Node Details: `Success?`
- **Type and Technical Role:** `n8n-nodes-base.if` (Conditional Routing Node)
- **Configuration Choices:** Evaluates whether the API response indicates success using loose type validation.
- **Key Expressions or Variables:** Left Value: `={{ $json.success }}` evaluated as `true`.
- **Input / Output Connections:** Input: `Brand-Pipe process` | Outputs: `Download result` (true branch), `Stop with error` (false branch)
- **Version-Specific Requirements:** Type version 2.2.
- **Edge Cases or Potential Failure Types:** Unexpected API payload structures may cause evaluation failures if the `success` boolean is absent.

---

#### Block 1.3: Output & Error Handling
- **Overview:** Retrieves the processed video file into binary data for downstream integration or halts execution cleanly with the corresponding API error message.
- **Nodes Involved:** 
  - `Download result`
  - `Stop with error`

##### Node Details: `Download result`
- **Type and Technical Role:** `n8n-nodes-base.httpRequest` (File Download Node)
- **Configuration Choices:** Performs a `GET` request to download the rendered MP4 file, storing it directly into the binary property `video`.
- **Key Expressions or Variables:** URL: `={{ $json.data.result_url }}`
- **Input / Output Connections:** Input: `Success?` (True branch) | Output: None (Terminal node for this branch; connects to downstream publishing/storage nodes)
- **Version-Specific Requirements:** Type version 4.2.
- **Edge Cases or Potential Failure Types:** Expired result URLs or network interruptions during file download.

##### Node Details: `Stop with error`
- **Type and Technical Role:** `n8n-nodes-base.stopAndError` (Error Termination Node)
- **Configuration Choices:** Halts workflow execution and outputs a formatted error message.
- **Key Expressions or Variables:** Error Message: `=Brand-Pipe error: {{ $json.error }}`
- **Input / Output Connections:** Input: `Success?` (False branch) | Output: None (Terminal node)
- **Version-Specific Requirements:** Type version 1.
- **Edge Cases or Potential Failure Types:** Missing error property in the API response will output undefined text.

### 4. Reproducing the Workflow from Scratch

1. **Create Credentials:**
   - In n8n, navigate to **Credentials** and create a new **Header Auth** credential.
   - Name the credential `Brand-Pipe API Key`.
   - Set the header name to `X-API-Key` and enter your Brand-Pipe API key as the value.

2. **Add Manual Trigger:**
   - Create a **Manual Trigger** node (`n8n-nodes-base.manualTrigger`) named `Run`.

3. **Add Parameter Assignment Node:**
   - Create an **Edit Fields (Set)** node (`n8n-nodes-base.set`) named `Set video`.
   - Connect `Run` to `Set video`.
   - Configure the assignments:
     - `video_url` (String): `https://test-videos.co.uk/vids/bigbuckbunny/mp4/h264/360/Big_Buck_Bunny_360_10s_1MB.mp4`
     - `logo_url` (String): `https://www.brand-pipe.com/logo.png`
     - `format` (String): `vertical`
     - `audio_normalize` (Boolean): `true`

4. **Add API Request Node:**
   - Create an **HTTP Request** node (`n8n-nodes-base.httpRequest`) named `Brand-Pipe process`.
   - Connect `Set video` to `Brand-Pipe process`.
   - Set Method to `POST` and URL to `https://api.brand-pipe.com/v1/process`.
   - Set Authentication to `Generic Credential Type` -> `Header Auth` -> select `Brand-Pipe API Key`.
   - Configure Options: Set Timeout to `300000` (5 minutes) and enable **Never Error** under response options.
   - Set Body Content Type to `JSON`.
   - Set JSON Body expression:
     ```javascript
     ={{ JSON.stringify({ video_url: $json.video_url, logo_url: $json.logo_url, format: $json.format, audio_normalize: $json.audio_normalize }) }}
     ```
   - Add a Header parameter:
     - Name: `Idempotency-Key`
     - Value: `={{ JSON.stringify({ video_url: $json.video_url, logo_url: $json.logo_url, format: $json.format, audio_normalize: $json.audio_normalize }).hash('sha256') }}`

5. **Add Conditional Logic Node:**
   - Create an **If** node (`n8n-nodes-base.if`) named `Success?`.
   - Connect `Brand-Pipe process` to `Success?`.
   - Set the condition left value to `={{ $json.success }}` with operator `Boolean` -> `Equal` -> `true`. Enable loose type validation.

6. **Add File Download Node (Success Branch):**
   - Create an **HTTP Request** node (`n8n-nodes-base.httpRequest`) named `Download result`.
   - Connect the **true** output of `Success?` to `Download result`.
   - Set Method to `GET` and URL to `={{ $json.data.result_url }}`.
   - In Options -> Response, set Response Format to `File` and Output Property Name to `video`.

7. **Add Error Termination Node (Failure Branch):**
   - Create a **Stop and Error** node (`n8n-nodes-base.stopAndError`) named `Stop with error`.
   - Connect the **false** output of `Success?` to `Stop with error`.
   - Set Error Message expression: `=Brand-Pipe error: {{ $json.error }}`
